LECTURE MEMORY: MA4829 Machine Intelligence (Visual Intelligence) - Continuous Assessment 2

Main Ideas:
- Robot color perception can be represented by averaging RGB vectors over time.
- Curves on planar surfaces (lines, circles, cubic curves) can be recognized by extracting parameters and using neural networks.
- Camera coordinate transformations involve converting world coordinates to camera coordinates, then to image coordinates.
- Image pixel coordinates relate to spatial coordinates via pixel size and image resolution.
- Mapping between workspace coordinates and image plane coordinates requires understanding camera parameters and pixel scaling.
- Straight line equations in workspace and image coordinate systems can be interconverted using pixel size and image origin.
- Circle equations in image coordinates can be transformed to workspace coordinates by scaling and translation.
- 2D vision matrices map image pixel coordinates to workspace coordinates using matrix multiplication and solving simultaneous equations.
- Binocular vision systems measure 3D surfaces and calculate distances from points to planes using plane equations.
- Distance from a point to a plane is computed using the plane equation and point coordinates.

Formulas/Theorems:
- Mean color vector: \(\vec{C} = \frac{1}{n} \sum_{i=1}^n (R_i, G_i, B_i)\)
- Line equation: \(v = a u + b\)
- Circle equation in image coordinates: \((u - u_0)^2 + (v - v_0)^2 = r^2\)
- Coordinate transformation: \(P_c = R P_w + T\) (world to camera)
- Pixel size: \(\text{pixel size} = \frac{\Delta x}{\Delta u}\), \(\frac{\Delta y}{\Delta v}\)
- Distance from point \(A(x_0,y_0,z_0)\) to plane \(Ax + By + Cz + D = 0\):
  \[
  d = \frac{|A x_0 + B y_0 + C z_0 + D|}{\sqrt{A^2 + B^2 + C^2}}
  \]
- Image to workspace coordinate conversion:
  \[
  x = A_v (u - u_0), \quad y = D_v (v - v_0)
  \]
- Neural network for curve recognition: input vector formed from curve parameters (line: slope/intercept; circle: center/radius; cubic: polynomial coefficients)

Pitfalls:
- Confusing coordinate systems (world, camera, image) and their origins.
- Ignoring pixel size when converting between image and workspace coordinates.
- Not accounting for image resolution and index coordinate origin offset.
- Misinterpreting the direction of axes in image and workspace.
- Incorrectly applying plane distance formula without absolute value or denominator normalization.
- Overlooking the need to extract curve parameters before classification.

Example Problem Types:
- Calculating mean RGB vector from multiple sensor readings.
- Designing neural networks to classify curve types based on parameter vectors.
- Converting 3D world coordinates to 2D image coordinates using camera parameters.
- Determining pixel size from known displacements in workspace and image.
- Finding workspace coordinates from image pixel indices and pixel size.
- Deriving equations of lines or circles in workspace coordinates from image plane equations.
- Computing distance from a 3D point to a planar surface.
- Using 2D vision matrices to map image points to workspace coordinates.
