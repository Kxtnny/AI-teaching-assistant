LECTURE MEMORY:  
- Large Language Models (LLMs) use transformer architectures to generate natural language by predicting tokens in sequences.  
- Tokens are units of text (words, subwords, characters) mapped to embeddings that capture semantic relationships.  
- LLMs like ChatGPT have billions of parameters enabling high-accuracy next-token prediction.  
- Prompts are critical inputs that guide LLM outputs; small changes in prompts can significantly affect performance.  
- Prompt engineering customizes LLM behavior by providing structured instructions that constrain style, format, and content.  
- Effective prompt engineering improves relevance and accuracy of LLM responses in educational and other applications.  
- Automatic Prompt Engineer (APE) techniques automatically generate task-specific instructions, enhancing zero-shot performance.  
- Chain-of-Thought (CoT) prompting asks LLMs to generate intermediate reasoning steps, improving multi-step reasoning accuracy.  
- Active Prompting selects informative examples to further boost CoT prompting effectiveness.  
- Existing work often focuses on high-level LLM reliability and hallucination mitigation, with less emphasis on dedicated educational chatbot prompting tools.  
- Manual prompt design is often inefficient and challenging for non-experts.  
- The proposed prompting tool integrates APE and Active CoT within educational chatbots to refine user prompts automatically.  
- This tool aims to improve answer reliability, reduce hallucinations, and encourage step-by-step reasoning by emphasizing clear task constraints.  
- Improved prompting leads to more robust and accurate educational chatbot responses.  

Formulas/Theorems:  
- No explicit formulas or theorems presented; focus is on conceptual methods and techniques in prompt engineering.  

Pitfalls:  
- LLM outputs are highly sensitive to prompt wording; minor prompt changes can degrade performance.  
- Manual prompt engineering can be inefficient and inaccessible to non-expert users.  
- Hallucinations (fabricated or unsupported outputs) remain a challenge without proper prompt constraints.  

Example Problem Types:  
- Multi-step reasoning tasks (e.g., arithmetic problems like MultiArith, GSM8K benchmarks).  
- Zero-shot reasoning tasks where no task-specific training examples are provided.  
- Educational chatbot queries requiring accurate, stepwise explanations and reliable answers.
